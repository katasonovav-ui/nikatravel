## Що можна перевірити на сайті

- **Головна** — популярні напрямки, переваги агенції та відгуки.
- **Тури** — каталог із фільтрами за країною, бюджетом і тривалістю, сортуванням та кнопкою «Показати більше».
- **Про нас** — інформація про агенцію та блок «Хто ми такі?», який можна розгорнути.
- **Контакти** — форма зворотного зв’язку з перевіркою email або номера телефону. Заявка демонстраційна й зберігається в браузері.
- **Мобільна версія** — меню відкривається через кнопку ☰, а картки популярних напрямків розміщуються в одну колонку.

## Технології та запуск

HTML5, CSS3, JavaScript і SVG. Для локального перегляду відкрийте `index.html` у браузері. Файли стилів, скриптів і зображень містяться в папках `css/`, `js/` та `images/`.
